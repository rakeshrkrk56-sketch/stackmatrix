## Which Mailchimp plans include API access and webhooks?

**Short answer:** Mailchimp API keys can be created on any account, but the webhook step in Mailchimp automations needs Standard or Premium; Free and Essentials are prompted to upgrade.

## What is the difference between developer webhooks and workflow webhooks?

Vendors use "webhooks" for two different features. **Developer webhooks** let an app or a tool like Make or Zapier subscribe to events, and are usually available wherever the API is. A **webhook automation action** is a no-code step that sends data out from the tool's own automations, and is often limited to paid plans. The table lists them separately so you can see which one an integration actually needs.

## Mailchimp API access: frequently asked questions

### Does Mailchimp Free include API access?

Yes. No plan requirement in Mailchimp's API key article. Mailchimp API keys can be created on any account, but the webhook step in Mailchimp automations needs Standard or Premium; Free and Essentials are prompted to upgrade.

### Which Mailchimp plans include webhooks?

Webhooks are available on Standard and Premium, but not on Free and Essentials. Webhook automation action by plan — Free: Upgrade prompt; Essentials: Upgrade prompt; Standard: Yes; Premium: Yes.

### Which Mailchimp plan do integrations need?

In this index: Free for 7 integrations; Essentials for 2 integrations; Standard for 2 integrations.
