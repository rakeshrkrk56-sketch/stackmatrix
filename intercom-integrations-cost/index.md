## Does Intercom force an upgrade?

Not for any of the 3 integrations here: each one works on Intercom's cheapest plan with API access, so the integration itself adds no Intercom upgrade cost. Any extra cost comes from the other tool's plan or from a connector fee, shown in the table above.

## Which Intercom integrations need Make or Zapier?

None of the 3: every Intercom integration here has a native connector, so there's no Make or Zapier fee unless you choose one.

## Which Intercom plans include API access and webhooks?

On the plans these integrations need: Essential (API access: yes; webhooks: yes). ## Intercom integration costs: frequently asked questions

### Which Intercom plan do I need for integrations?

Of the 3 Intercom integrations in this index, 3 work on Intercom's Essential plan. None needs a higher plan. Each pair's calculator shows the exact minimum plan on both sides.

### Which Intercom integrations need Zapier or Make?

None of the 3 integrations here; each has a native connector.

### How much does a Intercom integration cost for a 10-person team?

Including both tools' minimum plans and any connector fee, the 10-seat monthly totals range from $390.00 (Intercom + HubSpot) to $390.00 (Intercom + Stripe), at monthly-billing prices.
