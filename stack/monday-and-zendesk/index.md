## How the Monday.com + Zendesk integration works

monday.com's Zendesk integration creates board items from Zendesk tickets, with filters on fields such as ticket type, status and priority, so other teams can track support work on a monday.com board.

**Limitations:** Only the ticket's initial comment is pulled into the item's updates, and that section doesn't keep syncing. You need to be a Zendesk admin on a Zendesk plan of Team or higher.

Middleware via Make/Zapier would add ~$10.59/mo on top of the cheapest API-capable tiers ($840.59/mo all-in) — the native path is cheaper.

## Native vs middleware for Monday.com + Zendesk

The native path runs on the required tiers (Monday.com 'Standard' + Zendesk 'Suite Team') at $830.00/mo for a 10-seat team, with no middleware fee. The middleware path — the cheapest API-capable tiers plus about $10.59/mo for Make Core — would cost $840.59/mo all-in, so on cost alone there is no reason to switch: middleware would only make sense if you already run other automations through it.

API access at the required tiers: Monday.com Yes, Zendesk Yes (see the spec matrix). That API access is what the middleware path runs on.

## Frequently asked questions

### What are the minimum plan tiers required for the Monday.com + Zendesk integration?

To unlock the native integration, Monday.com must be on the 'Standard' plan or higher and Zendesk must be on the 'Suite Team' plan or higher. Neither plan is an upgrade over the cheapest plan with API access.

### How much does the Monday.com + Zendesk stack cost per month for a 10-person team?

At 10 seats with the required tiers (Monday.com 'Standard' + Zendesk 'Suite Team'), the stack costs $830.00 per month.

### Is the Monday.com + Zendesk integration native, and would Make or Zapier be cheaper?

The Monday.com + Zendesk connection is native — no third-party middleware subscription is required. Make would cost about $840.59/month on the cheapest API plans, more than the native route, so it only makes sense if you already use it.

### What are the limitations of the Monday.com + Zendesk integration?

Only the ticket's initial comment is pulled into the item's updates, and that section doesn't keep syncing. You need to be a Zendesk admin on a Zendesk plan of Team or higher.
