## How the Zendesk + Asana integration works

**Does Zendesk integrate with Asana?** Yes. Asana builds a Zendesk integration: agents create Asana tasks, with attachments, or link existing ones from a Zendesk ticket, and the task's status and owner show in Zendesk while the ticket's title, number and assignee show in Asana.

From a ticket, an agent creates a task or links an existing one. In Asana, a widget on the task shows who owns the ticket, its status and when it was last updated; when the task's assignee, due date or completion status changes in Asana, Zendesk is updated too. Asana rules can also add a comment to the Zendesk ticket automatically.

### How do you set up Zendesk + Asana?

1. In Zendesk, open the Asana listing in the Zendesk Marketplace, add it and sign in to Asana.
2. In Asana, open the project where tickets should go, click Customize in the upper right, scroll to Apps and select + Add app.
3. Select Zendesk and follow the on-screen instructions to sign in to Zendesk.
4. Open a ticket in Zendesk and create a new Asana task or link an existing one.

Steps follow [Asana's setup guide ↗](https://asana.com/apps/zendesk), read Nov 12, 2026.

**Limitations:** Only the fields Asana lists sync: the task's assignee, due date and completion status go to Zendesk, and the ticket's title, number, owner and status show in Asana. Asana says the integration is available to customers of both tools and names no plan, so this page models each tool's cheapest plan with API access (Asana Starter, Zendesk Suite Team).
