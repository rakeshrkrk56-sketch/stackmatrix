## Two kinds of webhooks

Vendors use "webhooks" for two different features. **Developer webhooks** let an app or a tool like Make or Zapier subscribe to events, and are usually available wherever the API is. A **webhook automation action** is a no-code step that sends data out from the tool's own automations, and is often limited to paid plans. The table lists them separately so you can see which one an integration actually needs.

## ActiveCampaign API access: frequently asked questions

### Does ActiveCampaign Starter include API access?

Yes. Every ActiveCampaign plan includes API access and webhooks: ActiveCampaign's help center lists Starter, Plus, Pro and Enterprise for both.

### Which ActiveCampaign plans include webhooks?

Webhooks are available on Starter, Plus and Pro. Webhook automation action by plan — Starter: Yes (help center lists all plans); Plus: Yes; Pro: Yes.

### Which ActiveCampaign plan do integrations need?

In this index: Starter for 3 integrations; Plus for 1 integration.
