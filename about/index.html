3-step verification methodology

Step 1 — Audit official pricing pages. For each tool we record per-seat or per-user pricing for every public plan tier directly from the vendor's own pricing page (linked below). Two exceptions are flagged wherever they apply: Pipedrive's prices come from an indexed copy of its pricing page and Make's monthly price from third-party reviews, because both sites block automated checks. ActiveCampaign, Pipedrive and Salesforce publish annual-billing rates only, so those are the rates used.

Step 2 — Audit API & webhook tier gates. We read each vendor's developer documentation and API rate-limit pages to identify exactly which plan tier unlocks API access, outgoing webhooks, and custom integrations — plus any paid API add-ons (e.g. Salesforce's $25/user/month API add-on on Professional). This gate is flagged as the integration's "hidden cost trap" because it is the most commonly missed expense.

Step 3 — Model middleware alternatives. Where no native path exists (or the native path forces an expensive tier jump), we price the connection through published Zapier and Make plan pricing, so the "via middleware" total reflects reality — and the calculator lets you compare both totals at your team size.

Pricing pages for 17 of the 20 tools below were re-checked between Nov 3 and Nov 5, 2026; API documentation and the remaining pricing pages were last audited in October 2026. When a vendor changes a price or tier gate, the mismatch is flagged for re-verification — never silently rewritten.
