## The $25/user/month API trap, explained

Salesforce gates its REST and Bulk APIs behind Enterprise — or a paid
add-on on Professional. For a 40-person sales team, that's an extra
 **$12,000/year** just to let your other tools talk to
Salesforce. Always model this surcharge before comparing Salesforce
against HubSpot or Pipedrive.

## Salesforce integration costs: frequently asked questions

### Does Salesforce charge extra for API access?

On Professional, yes: in this index Professional ($100/user/month) needs a $25/user/month API add-on before other tools can connect to it, while Enterprise and above include API access. Salesforce's current Slack app needs Enterprise or higher.

### What's the cheapest way to integrate Salesforce with other tools?

Salesforce Starter has no API access in this index, so middleware can't run on it either. The cheapest API-capable setup is usually Professional plus the $25/user add-on; Slack is the exception, because Salesforce's current Slack app needs Enterprise.
