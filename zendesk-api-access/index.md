## Two kinds of webhooks

Vendors use "webhooks" for two different features. **Developer webhooks** let an app or a tool like Make or Zapier subscribe to events, and are usually available wherever the API is. A **webhook automation action** is a no-code step that sends data out from the tool's own automations, and is often limited to paid plans. The table lists them separately so you can see which one an integration actually needs.

## Frequently asked questions

### Does Zendesk Suite Team include API access?

Yes. The limit is 200 requests/min. Zendesk's API is on every Suite plan with a per-minute limit by plan, and webhooks are included from Suite Team up.

### Which Zendesk plans include webhooks?

Webhooks are available on Suite Team, Suite Growth and Suite Professional. Webhook automation action by plan — Suite Team: Via triggers; Suite Growth: Via triggers; Suite Professional: Via triggers.

### What are Zendesk's API rate limits by plan?

Suite Team: 200 requests/min; Suite Growth: 400 requests/min; Suite Professional: 400 requests/min. Enterprise gets 700 requests a minute and Enterprise Plus 2,500; a High Volume API add-on (Growth and up, 10+ seats) raises the limit to 2,500.
