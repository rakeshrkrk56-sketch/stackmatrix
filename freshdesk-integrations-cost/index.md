## Does Freshdesk force an upgrade?

Not for any of the 3 integrations here: each one works on Freshdesk's cheapest plan with API access, so the integration itself adds no Freshdesk upgrade cost. Any extra cost comes from the other tool's plan or from a connector fee, shown in the table above.

## Which Freshdesk integrations need Make or Zapier?

1 of the 3 has no native connector and runs through a third-party service: Freshdesk + ActiveCampaign (Make Core, $10.59/mo). Connector fees are the monthly-billing price; the calculators use the lower annual-billing price (Make Core $9, Zapier Professional $19.99, Data Mapper $12.75) when you switch on annual billing. Real usage can push Make or Zapier onto a bigger plan, so check your expected volume.

## Freshdesk integration costs: frequently asked questions

### Which Freshdesk plan do I need for integrations?

Of the 3 Freshdesk integrations in this index, 3 work on Freshdesk's Growth plan. None needs a higher plan. Each pair's calculator shows the exact minimum plan on both sides.

### Which Freshdesk integrations need Zapier or Make?

1 of the 3 has no native connector: ActiveCampaign (Make Core, $10.59/month).

### How much does a Freshdesk integration cost for a 10-person team?

Including both tools' minimum plans and any connector fee, the 10-seat monthly totals range from $230.00 (Freshdesk + HubSpot) to $255.59 (Freshdesk + ActiveCampaign), at monthly-billing prices.
