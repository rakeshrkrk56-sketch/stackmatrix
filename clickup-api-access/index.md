## Two kinds of webhooks

Vendors use "webhooks" for two different features. **Developer webhooks** let an app or a tool like Make or Zapier subscribe to events, and are usually available wherever the API is. A **webhook automation action** is a no-code step that sends data out from the tool's own automations, and is often limited to paid plans. The table lists them separately so you can see which one an integration actually needs.

## ClickUp API access: frequently asked questions

### Does ClickUp Free include API access?

Yes. The limit is 100 requests/min per token. ClickUp's public API, including API webhooks, is available on every ClickUp plan; rate limits are 100 requests a minute per token until Business Plus.

### Which ClickUp plans include webhooks?

Webhooks are available on Free, Core and Business. Webhook automation action by plan — Free: Not stated; Core: Not stated; Business: Not stated.

### What are ClickUp's API rate limits by plan?

Free: 100 requests/min per token; Core: 100 requests/min per token; Business: 100 requests/min per token. ClickUp also has a "Call webhook" automation action; its help center doesn't say which plans include it. Business Plus raises the API limit to 1,000 requests a minute.
